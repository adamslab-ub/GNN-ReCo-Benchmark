# Supplement Material for IDETC 2026 Paper

This repository contains the supplementary material for the IDETC 2025 paper titled:

**Learning-based Directed Graph Abstraction of Combinatorial Spaces for Order-Preserving Search in Mixed-Combinatorial Nonlinear Optimization**

The original benchmark problems can be found in [MINLPLib](https://www.minlplib.org/). The combination sets in the paper are created based on the selected problems in the website and can be found in the folder in this repo.
